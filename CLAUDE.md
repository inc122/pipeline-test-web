# CLAUDE.md

Небольшой web-проект на Node.js (Express 5) с двумя эндпоинтами и тестами.

## Команды

- `npm install` — установить зависимости
- `npm start` — запустить сервер (порт `3000` или из переменной `PORT`)
- `npm test` — запустить все тесты
- `npm run test:one -- "<шаблон>"` — запустить тесты, чьё имя (`describe`/`it`) совпадает с шаблоном, например `npm run test:one -- "GET /sum"`

## Структура

- `src/app.js` — Express-приложение и маршруты; экспортирует `app` без вызова `listen`, чтобы его можно было тестировать напрямую
- `src/server.js` — точка входа, запускает `app.listen`
- `test/*.test.js` — тесты на встроенном `node:test` + `node:assert/strict` и `supertest`

## Эндпоинты

- `GET /` — возвращает текст `Hello World`
- `GET /sum?a=<число>&b=<число>` — возвращает JSON `{ "a": 2, "b": 3, "result": 5 }`; если параметр отсутствует или не число — `400` и `{ "error": "..." }`

## Общие Правила
- для каждой новой фичи добавляем соответствующий тест

## Правила арифметических эндпоинтов
- простые операции принимают 2 параметра на входе и возвращают ответ в JONS  вида `{ a: number, b: number, result: [значение] }`

## Соглашения

- Модули CommonJS (`require` / `module.exports`)
- Новые маршруты добавляются в `src/app.js`; на каждый эндпоинт пишется тест в `test/`
- Тестовый раннер — `node --test`, без Jest/Mocha; сторонние зависимости добавлять только при необходимости
