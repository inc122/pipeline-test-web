Ты работаешь в loop. Каждый запуск — одна итерация со свежим контекстом.
Память между итерациями — только файлы (PLAN.md) и git.

## Итерация
1. Прочитай CLAUDE.md, PLAN.md.
2. Если все критерии готовности выполнены вызови `core-review`. Закоммить правки, обнови `CLAUDE.md` если нужно и выведи последней строкой: `LOOP_STATUS: DONE`.
3. Иначе возьми первый шаг `[ ]` (или `[~]`, если он остался с прошлой итерации). Пометь `[~]`.
4. Сделай шаг. Добавь тест используя данные проверки в описании. Выполни тест, выполнение должно быть чистым.
5. Отметь `[x]`, `git add -A && git commit -m "step N: ..."`.
6. Последней строкой выведи `LOOP_STATUS: CONTINUE`.

## Когда остановиться и позвать человека
- Тот же шаг не получается третью итерацию подряд
- Реалиация фичи требует уточнений
Тогда: пометь шаг `[!] BLOCKED: <причина>`, выведи `LOOP_STATUS: BLOCKED`.
